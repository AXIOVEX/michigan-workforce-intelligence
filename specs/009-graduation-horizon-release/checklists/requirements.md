# Specification quality and release checklist

- [x] User value, geography, cutoff, scenarios and scope are explicit.
- [x] Requirements are measurable and map to tasks.
- [x] Program review horizons are distinguished from extinction predictions.
- [x] Proposals, observed evidence, projections and source conflicts remain distinct.
- [x] Missing inputs and environment limitations have explicit handling.
- [x] All numeric records trace to inspected artifacts.
- [x] All PDF pages visually inspected.
- [x] Local required gates recorded with honest outcomes.
- [x] AEE assessments, challenges, graph, ledger verification and gaps preserved.
- [ ] New release and download checksums verified.
